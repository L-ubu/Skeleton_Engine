02What you get

◆ Gesture → anything

Keypresses, mouse movement and clicks, shell commands, and multi-step macros — mapped per gesture.

◆ Debug overlay

Live skeleton render with gesture label, finger state indicators and confidence tracking. Great for demos.

◆ Mouse mode

--mouse turns your hand into the cursor. Pinch to click. Surprisingly usable.

◆ Selective gestures

--gestures open_palm,fist enables only what you need — fewer misfires, faster loops.

◆ Headless option

--no-debug drops the window entirely and runs as a quiet background recognizer.

◆ A studio, if you want one

Prefer drag-and-drop over config files? Skeleton_Studio is the visual builder on top of this engine.

04Why it exists

The decisions worth knowing about, written down.

Webcam first, no hardware

No Leap Motion, no gloves, no depth camera. If your Mac has a webcam, you already own the sensor.

On-device, always

MediaPipe runs locally — your camera feed never leaves the machine. Gesture control without the surveillance.

A CLI core, not a monolith

The engine is deliberately a small, scriptable binary. It powers Skeleton_Studio, kiosk demos, and whatever you wire it into next.
